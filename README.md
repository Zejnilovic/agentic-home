# agentic-home

A kit for your home folder: skills you want in every project on your machine, installed and kept up to date by [agd](https://github.com/Zejnilovic/agd).

```bash
agd --home init
```

To update it later:

```bash
agd --home update
```

The files land in `~/.claude/`, and a file you already have at the same path is left alone. See [Install for every project](https://zejnilovic.github.io/agd/guides/home/).

## What's in it

| Pack | What it does |
|---|---|
| `kit-authoring` | A skill that guides an agent through creating a kit: its purpose, packs, files, `agd check`, a trial install and the release. |
